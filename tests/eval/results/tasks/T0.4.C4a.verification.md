# C4a local verification plan

Run on Node 24 against the final implementation commit.

1. `npm ci` must exit 0 with the root lockfile unchanged.
2. `npm run check` must exit 0.
3. `npm test` must exit 0 and execute the command-contract suite alongside all existing suites.
4. `npm test -- --task T0.4.C4a` must exit 0 with the named public-interface cases.
5. `git diff --exit-code origin/main -- .no-mistakes.yaml` must exit 0.

The public test command covers draft-only and Git targets, no-commit Git resolution, new paths, internal and escaping links, traversal, unknown arguments and fields, all four result statuses, unchanged targets and scratch outside the target.
Record stdout and stderr beside the task evidence, with the source revision and actual OS, Node, npm and Git versions.
Run no-mistakes with `--skip ci` because the repository declares no hosted CI.
After publication, repeat installation, check and the full suite on the exact published head and put that SHA and test counts in the PR body.

C4b and C4c are pending, so this evidence does not complete T0.4 or claim child execution, fingerprints, schema validation or production dispatch.
Only the actual local operating system is verified.
An evidence-only commit above the tested implementation commit does not need to name itself.
