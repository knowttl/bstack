# C19 verification plan

Run on the final implementation commit using Node 24 or later:

1. `npm ci --ignore-scripts` and `npm ci --omit=dev --prefix skills/repo-audit` prepare root and installed skill dependencies.
2. `npm run check` verifies the complete skill package, links and language policy.
3. `npm test` validates all registered behavior, including T3.2 native clean/private/alias/cycle cases in both stacks and T3.3 baseline growth/removal/selection cases.
4. The gate's own final full-suite capture supplies task evidence through `node scripts/task-evidence.mjs .cache/full-suite.json T3.1`, `node scripts/task-evidence.mjs .cache/full-suite.json T3.2` and `node scripts/task-evidence.mjs .cache/full-suite.json T3.3`.
5. Preserve `.no-mistakes.yaml` byte-identical and add no workflows.

The native fixtures use the merged research's TypeScript compiler resolver and Python AST boundary check.
No native baseline feature was found for either, so the custom baseline compares normalized complete native diagnostic identities.
Missing native tools must be recorded blocked with the exact missing executable, never replaced by synthetic proof.
Local Linux execution cannot substitute for real Windows or macOS evidence.
Rule-proof covers the seeded static cases only; dynamic dependencies and unsupported syntax remain coverage limits.
