# C21 local verification

Install the committed root and skill runtime locks with `npm ci --ignore-scripts` and `npm ci --omit=dev --prefix skills/repo-audit`.
Run `npm run check` and `npm test` on the final committed implementation.
Run the registered public-command suites with `npm test -- --task T3a.1` and `npm test -- --task T3a.2`.
Contract controls cover version, existing and case-sensitive pointers, duplicate and unknown IDs, unsupported or escaping globs, child-command objects, native script cycles and aggregate recursion.
Collection controls cover committed, staged, unstaged, new, renamed and deleted paths, literal filenames, explicit empty-tree comparison, missing and shallow bases, candidate mapping and live recomputation.
Attach the gate's final full-suite capture with `node scripts/task-evidence.mjs .cache/full-suite.json T3a.1` and `node scripts/task-evidence.mjs .cache/full-suite.json T3a.2`.
The T3a.2 record must link AC-19 to the complete change inventory and AC-20 to unborn, missing-base and shallow-base controls.
Redaction is automatic and committed evidence stays lean.
Verify `.no-mistakes.yaml` is byte-identical to origin/main and no workflow files were added.
This public repository declares no CI; skip the pipeline CI step and quote the local verification results in the PR body with problem, consequence, fix and scope.
The PR targets knowttl/bstack main and remains for firstmate to merge.
Only Linux execution is recorded here; semantic assessment, arbitrary opaque leaf program analysis and real Windows/macOS execution remain outside this slice's evidence.
