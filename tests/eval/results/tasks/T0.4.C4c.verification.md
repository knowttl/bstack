# C4c local verification plan

Run on Node 24 against the final implementation commit.

1. `npm ci` must exit 0 without changing lockfiles.
2. `npm run check` must exit 0.
3. `npm test` must exit 0 with all existing suites and the schema-contract suite.
4. `npm test -- --task T0.4` must pass the complete shared-library suite.
5. `npm test -- --task T0.4.C4c` must pass the registered public command cases.
6. `git diff --exit-code origin/main -- .no-mistakes.yaml` must exit 0, and no workflow files may be added.

The schema-contract suite invokes the installed entry point with valid and invalid files under `tests/inputs/`.
It covers definition validation, named unsupported keywords, unknown fields, duplicate and missing IDs, data constraints, malformed JSON, read-only failure, resource resolution from another directory, and help without command implementations.
The complete T0.4 suite also verifies C4a targets and paths and C4b child commands and fingerprints.
Repeat C4c because its public interface performs file I/O.
Capture direct command output beside the task evidence.
Evidence names the last implementation commit it ran against.
An evidence-only commit above that implementation commit does not need to name itself.
Any source or test fix, including pipeline review or test fixes, must refresh the evidence record against the new implementation commit in the same round.
The PR body must state both evidence rules and quote verification results.

T0.4 done criteria map to slices as follows.
Unknown options, missing targets, non-Git workspaces and Git repos without commits are covered by C4a.
Traversal, escaping links and new paths under escaping parents are covered by C4a.
Unsupported schema keywords and invalid inputs with named problems are covered by C4c.
Literal arguments, Windows npm launcher selection, timeout and cancellation are covered by C4b.
C4b's Linux tests cover Windows selection logic, while real Windows execution remains pending under R26.
The PR body must state this slice mapping and platform limit.

Run no-mistakes with `--skip ci` because bstack declares no hosted CI.
Preserve `.no-mistakes.yaml` byte-identical and add no workflow files.
Licensing is out of scope under design R24.
After publication, confirm the PR is not a draft and is mergeable.
Run `npm ci`, `npm run check` and `npm test` once on the exact published head.
Add the PR body line `Local verification on <sha>: npm ci ok, check ok, tests <counts>`.
Firstmate merges the PR.

Only Linux execution is claimed by C4c.
The installed schema subset does not implement the root task-evidence schema's conditional keywords.
